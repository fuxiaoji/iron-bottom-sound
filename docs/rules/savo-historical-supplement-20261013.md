## 游戏尺度与原典约束

规则书 PDF3 / 印刷3，1.2：六角格边到对边约600码，每回合3分钟。不是400码。想定书 PDF10 / 印刷11给出四舰 H23、F24、D25、B26，航向1、速度5；首回合直接从炮击阶段开始。

鸟海至衣笠相距6格，即约3600码。5200 / 600 = 8.67，若采用最近整数格，可把鸟海至古鹰设为9格（5400码，差约200码）。古鹰因此在衣笠后3格，而非1格。6分钟约等于2回合，是粗略一致性检查，不用于断言“游戏第1回合就是0143”。

原典 R1 文字只说天龙、夕张、夕凪跟随衣笠，并没有给古鹰的部署值；图中却同时列出古鹰。因此把古鹰插入衣笠与天龙之间属于依据战史补全的历史变体，须明确标示，不能声称是原典文字自动推导。

计算方式：航向1每MF增加 q、减少 r；A27 为 `(0,26)`。因此古鹰第2MF到 A27，其余依次第3/4/5MF入场。表中的末位置以直行且没有交战改令为例。它不强制玩家后续保持历史航线。

必须同时说明三个限度：历史报告中的古鹰约0143已经射击，本候选却因地图裁边不能在游戏首轮射击；这是保留现有图幅/四舰原站位的代价，不能说是完整历史复现。后三舰一格间距也不复现战史约1300码的统一间距；它保留游戏特例。现引擎没有图外队列按MF入场机制，不能把它简化为增援阶段四舰同时放在同一入口；如实现，须有独立变体编号、队列状态、事件与确定性回放测试。

若要求古鹰首轮即可射击，应采用更大的带西侧海域的历史重建地图，并从战斗航迹图重新标定全部舰位；这已超出“只补一艘船”的修改，不能用本表冒充完成。
