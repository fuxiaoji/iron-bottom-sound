# 真实模式：编队指挥链

“真实模式”是项目扩展，不是原版规则勘误。关闭 `realistic_command` 时，阶段、订单、AI 和事件流仍走经典路径。

## 原版与扩展边界

- 原版玩家表第 4 页特殊损伤 31：舰桥命中；被击中舰下一回合保持原航速直航，舰长阵亡。
- 原版玩家表第 4 页特殊损伤 42：舰长阵亡；不附带强制直航。
- `IBS-R-RC-01` 至 `IBS-R-RC-07`：项目真实模式扩展，来源、执行点和测试在 `realistic-command.yaml` 单独审计。

## 玩家流程

1. 开局选择“真实模式”。想定 1、想定 3、二马先进入私密编队初设。
2. 每方把全部舰编入一至四队，每队至少两舰；设置领舰、旗舰、备用旗舰、纵队顺序、间距和舰首。
3. 移动阶段只填写领舰航路。引擎逐 MF 为后舰生成尾随航路并校验整队地形、转向、速度和冲突。
4. 某舰无法保持共同航速时，选择全队降速或永久脱队。脱队舰由撤退控制器接管、禁止发射鱼雷、自动选择合法炮击。
5. 旗舰舰长阵亡、旗舰沉没或退出时，备用旗舰优先继承。下一回合全队按上轮最终航向和实际速度直航；原版损伤和碰撞可以截断。

## 模块边界

- `models.py`：只定义可序列化状态与订单。
- `realistic_command.py`：扩展规则、编队订单展开、继承、撤退与 `RealisticCommander`。
- `engine.py`：经典裁决器只在选项开启时调用扩展钩子。
- `FormationPanels.tsx`：编队初设和编队移动表单；完整 JSON 仍是审计/高级入口。

历史设计背景：[1944 年美海军战争指令](https://www.ibiblio.org/hyperwar/USN/ref/WarInst/WarInst-12.html)、[埃斯佩兰斯角战斗命令](https://www.ibiblio.org/hyperwar/USN/USN-CN-Esperance/USN-CN-Esperance-3.html)。
