## 信息、记忆与兼容

阵营记忆只消费非调试观察、已接受命令及正式执行结果；历史接触带时间戳并明确不是实时坐标。提示读取和行动建议不写记忆，重试失败不提交记忆；同局跨刷新/服务重启/导入保存，新局不继承。日志按回合、阶段、阵营及编队过滤后分页，接受决策与阵营记忆有私有回放检查点。命令延迟模式沿用原编队授权和通信边界。

AI 调试/记忆导出及新版 debug 观察/敌方封存航迹需显式本地调试；正常观察不带记忆检查点、隐藏计划、未知沉没与私有鱼雷路线。完整战报在新版对局结束后开放。模型公开输出、解析、校验、耗时和重试可审计；私有推理、实际 API 密钥不落日志。

AI 回归使用五个状态机风格、双方席位、种子 1/13、S04/S06/S08/S10/FM-01、传统/真实两种模式的两回合合法性矩阵，检查友舰碰撞和夜战行动计数。它用于流程与信息边界检查，不能代表整局胜率或 AI 强度。受损烟幕策略另用合成条件检查，因为完整开局矩阵未必在两回合内触发重伤。

传统 AI 的安全检查包括本轮逐脉冲同格/交换格和下一轮本方首步可行性；避免“可停舰被强制前进舰堵住、其后又有跟舰”的三舰死端。航迹与下一轮必走格只在一次规划内缓存，每次规划清空；缓存不改变候选、评分、骰子流或信息权限。

验收产物保存在 `artifacts/night-20261013/`。全量回归、针对性回归、UI 截图、矩阵和正式库重启前后摘要的实际结果见 `havedone.md`。

2026-10-13真实GPT-6 Luna使用已有Codex登录，经CLI桥接正式游戏JSON解析/API校验管线；不是公共HTTP API密钥测试。10次决策请求得到7个首轮合法决策与3个连接超时；传统模式完整一回合、真实模式编队部署/增援/移动，记忆与存档核验一致，不代表整局胜率或强度。直接CLI未继承Windows系统代理，使用仅子进程环境中的现有代理后连通；不读取/复制登录令牌。`test_luna_live.py` 有调用上限、超时、禁用模型工具、临时会话与只收最终公开JSON的边界。

实测发现早期失败决策调试记录未进入回放。新增 `ai_decision_rejected` 私有审计检查点，失败仍不更新行动记忆；事件回放恢复失败记录。早期night-v2存档以game_id回放时可读取其既有拒绝审计缓存，事件独立回放不能补出旧日志本来没有的信息。新增边界测试覆盖失败回放、普通观察排除、旧缓存兼容和无记忆提交。

调试直接显示公开摘要、模型、阶段目标、逐舰意图、预案；展开后可看公开JSON、校验/重试和记忆快照。战报捕获丢弃私有reasoning参数，读取旧战报屏蔽原字段，Markdown/HTML/UI不展示私有推理，旧数据库原内容不改写。历史来源和具体图外队列候选见 `savo-historical-supplement-20261013.md`；Q024/Q025没有因此解除。
