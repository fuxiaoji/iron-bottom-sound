# E04 案例研究

## 案例一：鱼雷未命中但迫使目标改变行动（低直接命中子集）

- seed `21467821`，geometry=chase，fleet=1v1，低命中机会池 = 9 条航迹
- 发射机会: IBS-U-IJN-FUBUKI TT1 mf=2 port/B setting=0，齐射 2 枚，鱼雷航向 6，发射格 V18
- 对 τ0* 航线的直接命中期望 E[hits] = 0.0833（broadside，鱼雷航程 9 格），远低于阈值 0.15
- 基线 τ0*（A 条件）：plan `1S1S2P` → R11 h1 cost=4，J = 5.333（J_ref = 5.333）
- 威胁下最优响应 τT*（C 条件）：plan `1S1S2S` → R11 h3 cost=4，J = 5.333
- route_changed = True，航向变化 2×60°，速度变化 0 MF，终点偏移 0 格
- **V_denial = J(τ0*) − J(τT*) = 0.0000**（归一化 0.0000）
- 威胁恒定条件 D 的响应：route_changed = True，V_denial = 0.0000

解读：目标方确实对鱼雷航迹做出了反应（改变航迹/节奏以避开 (turn,impulse) 同格），但引擎炮位价值景观呈台阶状（本想定中 339 条合法路线只有 4 个不同 J 值，且最高档存在大量并列路线），目标可以在**零炮位价值损失**的前提下换到一条不接触航迹的并列路线 —— 机动剥夺真实发生，但其位置价值代价为 0。

## 案例二：直击威胁的位移威力（近距对照，威胁恒定条件 D）

- seed `21862516`，geometry=close，fleet=2v1
- 发射机会: IBS-U-IJN-HATSUYUKI TT1 mf=1 starboard/B setting=1，齐射 2 枚
- 直接命中期望 E[hits] = 1.139（broadside，鱼雷航程 1 格）——近距直击，威胁致命
- 基线 τ0*：W17 h1 cost=5，J = 34.667（J_ref = 34.667）
- C 条件（真实杀伤权重 w=0.343）：route_changed = False，V_denial = 0.0000（规避代价 0 格 / 0 MF 高于威胁折价）
- **D 条件（威胁恒定）：route_changed = True，V_denial = 18.5833（归一化 0.536）**

解读：同一条航迹一旦被视为“任何接触都不可接受”，目标愿意放弃 18.6 点炮位价值来规避 —— 航迹的位移威力存在；但在期望毁伤权重下（C 条件），规避代价仍高于威胁折价，理性目标不移动。剥夺价值由此完全取决于威胁权重，而非航迹几何本身。
