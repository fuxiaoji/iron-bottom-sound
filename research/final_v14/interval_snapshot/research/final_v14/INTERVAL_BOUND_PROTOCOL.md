# Supplemental interval-loss theorem and experiment

Development extension recorded2026-09-13, before any v14 frozen-test result. Development values have already been viewed; this candidate is not labeled an outcome-blind invention. The original physical design, primary solver, calendar comparisons and AUXILIARY_FREEZE remain unchanged.

Scope: fixed fully replanning opponent F only. For every candidate block[t,e), compare the fully replanning continuation value with the value of committing the focal player over that block and then allowing full updates. Take the maximum deficit over every executed prefix at t, preserving the full physical history. Include numerical continuation error. This yields an interval cost d(t,e). A sum of such costs bounds the value loss for a fixed calendar. A layered shortest-path computation minimizes this conservative bound under at most K updates. It supplies a feasible calendar and an upper bound on its loss; it does not alone certify that K is the smallest possible actual-performance budget.

Predeclared evaluations: all9 development and12 frozen-test physical configurations, opponent F; plus the three T4 Grid3 speed1 distance16 anchors and their three ablations, again F only. All interval pairs are included. No configuration is selected by bound tightness. The matched fully replanning value tree is preprocessing, and every local response game is charged. Compare each shortest-path calendar's bound with its independently enumerated value interval and with the true budget frontier; report preprocessing time, number of local solves, tightness and conservative retention-budget decisions. A case gets at most6hours and8GiB, and any incomplete interval map yields a reported unresolved case. No claim extends this public-boundary theorem to a committed opponent retaining private future commands.

The proof is an application of backward minimax perturbation and shortest-path dynamic programming. Its potential increment is an explicit calendar-level loss certificate and schedule selection without enumerating all calendars. It is not claimed as the first general Bellman error bound. Final utility and novelty remain empirical and literature questions.
